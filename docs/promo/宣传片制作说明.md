## 1. 一句话定位

**边说边出字，录音不上云。**

十个字，说完全部：前半句是体验，后半句是底线。片子的每一秒，都要为这十个字服务。

展开版（用于片尾落版或简介）：
> EchoNote 是一款开源的本地录音转写工具：说话时，字幕就在屏幕上长出来；停顿后，自动改写成带标点的定稿；一键导出 TXT / SRT / WAV / Markdown。模型装在本机，断网也能用——音频从不离开你的设备。

**三个必须传达的记忆点**（按顺序，少一个都不算达标）：

| # | 记忆点 | 观众看完应该记住的一句话 |
|---|---|---|
| M1 | 边录边出字 | "它是我说话的时候就在写，不是说完了才转。" |
| M2 | 定稿自动重写 | "停一下就变成带标点的整句，不用自己改。" |
| M3 | 断网可用 / 不上传 | "网断了它照样转，因为它根本没往外传。" |

## 2. 目标受众与场景

| 受众 | 他们的痛点 | 片子里给他看的镜头 |
|---|---|---|
| 教师 / 学生 | 课堂录音回来要重听两小时才能整理 | 会议模式连续出字 + 导出 Markdown 笔记 |
| 会议参与者 / 访谈者 | 记不全，会后要对着录音抠字 | 停顿后定稿重写 + SRT 字幕 |
| 技术从业者 / 工业现场 | 专业名词被听错（焦距听成脚距） | 术语纠错前后对比 |
| 隐私敏感者 / 内网环境 | 不敢把会议录音丢给云端 | 拔网线 / 飞行模式继续转写 |

主片只服务前三类；第四类的顾虑最重，放在 60 秒完整版里正面回应（见增补 C）。

## 3. 三版规格

| 版本 | 时长 | 画幅 | 用途 |
|---|---|---|---|
| **A · 主片** | 30 s | 1920×1080 / 30 fps | GitHub README 首屏、官网、B 站 / YouTube |
| **B · 竖屏** | 15 s | 1080×1920 / 30 fps | 抖音 / 视频号 / 小红书，静音也能看懂 |
| **C · 完整版** | 60 s | 1920×1080 / 30 fps | 发布说明、知乎 / 少数派嵌入 |

技术参数（三版通用）：
- 编码 H.264 High Profile，CRF 18–20，MP4 封装；另出一份无字幕母版（clean master）备二次剪辑
- 音频 48 kHz 立体声，整体响度 **−14 LUFS**（短视频平台统一口径），峰值 ≤ −1 dBTP
- 字幕为硬字幕，中文思源黑体 Medium；底部安全边距 ≥ 8%（竖屏 15%），避让平台 UI
- 交付：MP4 × 3 + 无字幕母版 + 封面图 1280×720 × 2（"出字中"与"定稿后"各一张）

## 4. 主片分镜（30 s · 8 个镜头）

节奏原则：**前 3 秒把痛点钉在屏幕上；3–26 秒一秒都不离开产品界面；最后 4 秒收拢、落版、给出行动。**

| # | 时间 | 画面 | 屏幕字幕 | 旁白（口播） | 声音设计 |
|---|---|---|---|---|---|
| 1 | 0:00–0:03 | 近全黑的会议室。一支录音笔的红色指示灯在呼吸，旁边是一摞没整理的纸质笔记。镜头极缓推近那一点红。 | `47 分钟的录音`<br>`整理要两小时` | "散会了。录音躺在那里。" | 只有低频环境音，混一丝心跳般的电流嗡鸣；无音乐 |
| 2 | 0:03–0:07 | 切到 EchoNote 深色界面（空态）。鼠标点下麦克风圆钮，波形亮起，光标开始逐字吐出第一句话。**必须是真实的逐字追加，不能是打字机特效伪造。** | — | "现在——你说，它写。" | 第一句字幕出现的那一下，是全场唯一一次"叮"（清亮、短、5 kHz 附近），之后不再重复 |
| 3 | 0:07–0:10 | 继续说话，字幕持续增长；底部状态行显示 `正在听 · 已 3 段 / 62 字`。镜头轻微下移，带出状态行。 | `边说边出字`（左侧竖排小字，青色） | "不用等说完，更不用等上传。" | 音乐进入：单音钢琴 / 极简电子脉冲，60 BPM，克制 |
| 4 | 0:10–0:15 | 说话停顿。那一句从浅灰变亮白，标点自动补上，行尾出现 `✓ 已精修`。**0.4 倍速慢放 + 局部放大，让观众看清"改"这件事。** | `停一下，自动改成整句` | "你停一下，它把这句话重写一遍：加标点，改错字。" | 音乐加一层薄弦；重写瞬间一个轻微"落笔"声 |
| 5 | 0:15–0:19 | 点导出，四个文件图标依次弹出、轻弹落位：TXT / SRT / WAV / MD。鼠标划过 SRT，画面右侧浮出一小段真实字幕时间轴。 | `TXT · SRT · WAV · MD` | "导出来，就是能用的笔记、字幕和原声。" | 四声清脆的落位音，音高递升 |
| 6 | 0:19–0:23 | **断网镜头**：任务栏 Wi-Fi 图标特写 → 飞行模式 / 拔网线。切回界面，字幕依旧在长。右下角"离线可用"绿角标亮起，镜头推近它。 | `断网了，它还在写` | "拔掉网线，它一个字都没少。" | 音乐抽掉低频，只留高频脉冲——世界安静了，它还在动 |
| 7 | 0:23–0:26 | 手机横入画面：Android 上同样的界面、同样的字在长。手机与桌面并排，两个波形同步起伏。 | `手机，同样本地跑` | "电脑、手机，一套体验，都在本地。" | 音乐回到主和弦，第一次给足音量 |
| 8 | 0:26–0:30 | 全黑。Logo 🎙 EchoNote · 声记 淡入，其下两行：`边说边出字 · 录音不上云` / `开源 · MIT · github.com/Qsianuo/echonote`。**GitHub 地址是本片的行动落点，把它做成落版里最亮的一行。** | 同左 | "EchoNote 声记。开源，免费，现在就装。" | 一记短促收尾，"装"字落下后留 0.3 s 静默 |

**旁白总字数约 100 字**，按 4.2 字/秒的中文口播约 24 秒，留 6 秒给画面呼吸。建议男声或中性女声，语速偏慢、句末下沉，不要广告腔。落版自 0:26 起，Logo 与 GitHub 地址清晰可读的时间 **≥ 3 秒**（手机屏上能看清）。

## 5. 竖屏 15 秒（静音可懂）

竖屏必须**首帧就有信息**，不许黑场铺垫，信息全部压在大字幕上。

| # | 时间 | 画面 | 大字幕（必须能静音读懂） |
|---|---|---|---|
| 1 | 0:00–0:03 | 直接进最精彩的一帧：字幕正在逐字长出来，手指在手机上点麦克风。 | 说话的时候<br>**字就在长** |
| 2 | 0:03–0:07 | 停顿 → 那句变白、补标点、`✓ 已精修`。 | 停一下<br>**自动改成整句** |
| 3 | 0:07–0:11 | 飞行模式图标 → 字幕继续长 → 绿角标。 | 开飞行模式<br>**照样转** |
| 4 | 0:11–0:15 | Logo + `开源 · 本地运行 · 免费` + GitHub 地址，地址做成本片里最大的一行可读文字。 | EchoNote 声记<br>**现在就装** |

竖屏不要旁白（多数平台默认静音打开）；只保留环境音 + 三次关键音效。若平台强制有声，用主片旁白的前三句裁剪。

## 6. 完整版 60 秒增补段落

在主片 8 个镜头之间插入以下三段（其余不变，镜头时长整体放慢）：

**增补 A（插在镜头 4 之后，约 8 s）· 为什么快**
画面：左右分屏示意。左侧"整段喂给大模型"，一堆方块卡在半路；右侧"音频连续流入、边流边解"，字幕持续长出。
字幕：`不切碎，不排队`。旁白："很多工具把录音切成小段，一句一句往里送，越切越慢。它让声音连续流进来——边流，边解。"

**增补 B（约 10 s）· 专业名词不会被听错**
画面：录一段含"焦距""曝光""模板匹配"的话，先给纠错前（错字用红色下划线标出），0.5 s 后逐词替换为正确写法。**必须用真实录音跑出来的对比，不能手搓。**
字幕：`专业词汇，按读音纠`。旁白："焦距，不会写成脚距；曝光，不会写成暴光。你的术语，你自己加进术语表。"

**增补 C（约 8 s）· 隐私说清楚**
画面：本机网络活动示意图——麦克风 → 本机进程 → 屏幕，箭头到此为止，外面画一圈虚线："没有出网"。
字幕：`音频不出这台机器`。旁白："没有账号，没有云端，日志里也不记你说的话。"

## 7. 视觉规范

**配色直接取自产品界面（`web/style.css`），不要另创色板：**

| 用途 | 色值 | 说明 |
|---|---|---|
| 主背景 | `#060d1a` | 近黑偏蓝，片头片尾与转场底色 |
| 面板 | `#0d1b30` | 界面卡片 |
| 主强调 | `#64ffda` | 字幕高亮、竖排小标签、Logo 描边 |
| 强调暗部 | `#2ea88b` | 次级文字、进度 |
| 正文 | `#ccd6f6` | 大字幕 |
| 次要 | `#7c8db5` | 说明文字 |
| 警示红 | `#ff5470` | **只用于"纠错前"的错字标记**，不作装饰 |
| 成就绿 | `#3ddc84` | "离线可用""已精修"角标 |

- 字体：中文 思源黑体 / HarmonyOS Sans Medium；英文数字 Inter；代码与文件名 JetBrains Mono
- 动效语气：**克制、精确、有机械感**——像一台精密仪器，不像一支广告。位移 ≤ 24 px，缓动 `cubic-bezier(.22,.61,.36,1)`；禁止弹跳、禁止光斑扫过、禁止 3D 翻转
- 界面取景：一律 100% 缩放录屏后裁切，**不要用缩放变形**把 UI 拉满；圆角保持原始 18 px
- 转场：只用硬切、0.2 s 黑场、纯色遮罩擦除三种。不使用粒子、光效、故障风

高级感来自克制，不来自堆料：深色底、一种强调色、真实运动的界面——这就是本片的视觉语言。

**禁止出现在画面里的东西**：代码编辑器、终端里的 `pip install`、模型文件名列表、架构图——这些是开发者内容，会劝退普通观众。

## 8. 素材清单与录制要点

### 8.1 已有素材（可直接复用）

| 素材 | 路径 | 备注 |
|---|---|---|
| 界面截图 | `docs/screenshot.png`、`docs/screenshots/` | 空态 / 录音中 / 字幕 / 导出菜单 / 窄屏 |
| 上版 30 秒片 | `docs/promo/echonote-promo.mp4`、`.gif` | **仅作参考**，画质与文案以本说明为准重做 |
| 导出样例 | `docs/examples/` | 四种格式的真实产出 |

### 8.2 必须新录的素材（4 条，缺任何一条，M1–M3 就讲不实）

1. **逐字出字**（镜头 2、3）：一次连续说话 ≥ 15 s，中途不要停，让字幕连续追加
2. **定稿重写**（镜头 4）：说完一句后停 2 s，录到灰→白、补标点、`✓ 已精修` 的全过程
3. **断网继续**（镜头 6）：先录到出字，切飞行模式/拔网线后再录 10 s
4. **术语纠错前后**（完整版 B）：读 3 句含专业词的话，保留纠错前文本（`tools/check_glossary.py` 可打印原文与纠错后文本，直接拿来做对比卡）

### 8.3 录屏前的产品设置（照做，否则素材不能用）

- `models/asr-backend.txt` 内容为 `sensevoice`（混合模式：实时 zipformer、定稿 SenseVoice 带标点）
- 双击 `fetch-model.bat` 确保模型已在本地，界面出现绿色「离线可用」角标
- 录制"会议/课堂"场景用**会议模式**；个人近讲镜头用个人模式——两种模式的切句手感不同，混用会显得界面在抖
- 术语表 `models/glossary.txt`（115 词）已就位；改完**重启应用**才生效
- 录音时长控制在 2 分钟内，避免触发 90 分钟软上限的提示弹窗
- 关闭其它会抢麦克风的程序；用外接麦，不要用笔记本内置麦录宣传素材（远场拾音会让演示字幕出错）
- 录制分辨率 1920×1080、系统缩放 100%、隐藏任务栏与通知；需要"断网"镜头时用飞行模式图标特写，不要真的黑屏

## 9. 表述红线（写完脚本逐条对照）

以下是**不能说的话**——说错一句，就是虚假宣传：

| ❌ 不能说 | ✅ 应说 | 原因 |
|---|---|---|
| "准确率 100%" / "零错误" | "本机 8.95 秒样本实测字符错误率 0%" | 0% 是单条样本的实测值，不是产品保证 |
| "实时转写 / 零延迟" | "边说边出字，首字约 2.8 秒" | 首字 2.8 s 卡在"2 s 缓冲 + 1 次解码"的物理下限 |
| "永远不上传 / 绝对安全" | "默认全程本地；远程模式需手动开启，且界面会改写提示" | 代码里保留了可选的远程识别通道 |
| "云同步 / 多端同步 / 历史记录" | — | **当前版本没有这些功能**，不能拍 |
| "说话人分离 / 自动摘要 / 实时翻译" | — | 没有，别画 |
| "支持所有语言" | "中英日韩法德西俄，可自动识别" | 有明确清单 |
| 直接用人声合成配"真人使用感受" | 用旁白陈述，或用真实用户素材并标明 | 避免伪造证言 |

补充：片尾必须出现 **MIT 开源** 与 GitHub 地址；若使用他人音乐/字体，需在简介中标注授权，不要用无授权商用曲库。
