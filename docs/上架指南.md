## 二、商店文案（直接复制）

**应用名**：EchoNote 声记 — 本地录音转写

**简短描述（≤80 字符）**：
```
离线录音转文字：本地识别不上传，实时字幕，一键导出 TXT/SRT
```

**完整描述**：
```
EchoNote 声记是一款"录音不出设备"的本地语音转写工具。

【核心特点】
■ 彻底离线 — 语音识别在你的手机上完成，录音与文字不经过任何服务器
■ 实时字幕 — 边说边出字，停顿后自动精修成带标点的定稿
■ 中文优化 — 内置中文流式模型 + 离线定稿模型，中英混说也可识别
■ 一键导出 — TXT / Markdown / SRT 字幕 / WAV 录音
■ 情境切换 — 个人模式（近讲低延迟）/ 会议模式（远场抗噪）
■ 录音暂停 — 一段录音随时暂停继续，时间轴自动对齐

【隐私承诺】
· 无账号、无广告、无统计、无追踪
· 麦克风只在录音时工作
· 卸载即彻底删除全部数据

【首次使用】
启动后需一次性下载约 270MB 离线识别模型（仅此一次需要网络），
之后飞行模式下可完整使用。

适合：会议记录、课堂笔记、采访速记、语音备忘。
```

**Google Play 数据安全表单答案**：
- 是否收集用户数据：**否**
- 是否共享数据：**否**
- 是否需要隐私政策：是 → 隐私政策 URL
- 权限申报：RECORD_AUDIO → "应用功能需要，数据不离开设备"
- 内容分级问卷：无暴力/无赌博/无社交 → 评级会是"所有人/3+"
- 目标受众：不做儿童定向 → 18+ 或全年龄（选全年龄需确认无诱导性内容）

## 三、三个商店的路线与顺序

### 3.1 Google Play（最快可上线，建议第一站）

1. 注册 Google Play Developer 账号（**$25 一次性**，需身份验证 + 2 天审核期；大陆银行卡/双币卡可付）
2. Play Console → 创建应用 → 填名称/描述/截图（用上面材料）→ 上传 AAB
3. 数据安全表单按第二节答案填；内容分级问卷提交
4. 隐私政策 URL 填 GitHub 链接
5. 提交审核（新应用首审通常 1-7 天）
6. ⚠️ 前提：注册和上传需要能访问 Google（自行解决网络）

### 3.2 国内安卓商店（华为/小米/OV/应用宝——面向大陆用户的正路）

**关键路径是两张证，建议立刻启动：**

1. **软件著作权（软著）**：个人可办，中国版权保护中心或代理，普通流程 1-2 个月（加急另付费）。所需材料：源代码前后各 30 页、说明文档、身份信息
2. **App 备案**（工信部 2024 年起强制）：需先有已完成 ICP 备案的网站主体（个人可备案），在商店提交时填备案号。通过你的网站/域名服务商走备案流程，2-4 周

之后各商店流程大同小异：注册开发者（个人实名认证）→ 上传 APK（正式签名版）→ 填软著号/备案号 → 隐私政策链接 → 权限使用说明（照抄本文档第二节权限表）→ 提交审核（每家 1-7 天）

⚠️ 个人主体在国内商店的限制：部分商店对个人开发者上架"工具类"友好（华为/小米可以），个别分类受限。若规划做成产品，注册个体户/公司主体更顺。

### 3.3 App Store（iOS）——仍卡两样

- Apple Developer $99/年
- 一台 Mac（构建+签名+上传必须）
- iOS 工程已生成完毕（`mobile/ios/`），届时半天内可出包。开通后告诉我，我出 iOS 包
