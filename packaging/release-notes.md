## 下载后怎么用（Windows，不需要装 Python）

1. 下载 `EchoNote-v0.10.0-windows-x64.zip`（约 102 MB，不含模型）
2. 解压到**任意可写目录**，例如 `D:\EchoNote` —— 不要放在 `C:\Program Files`
3. **双击 `fetch-model.bat`** 准备模型（默认高精度档约 1.6 GB，自动走国内镜像，只需一次）
4. 双击 `EchoNote.exe`，浏览器自动打开，点麦克风开始录音
5. 关闭命令行窗口即退出

模型放进 `models\` 之后，**识别全程零联网**。需要硬保证不联网的环境：

```
EchoNote.exe --offline
```

### 出问题先跑自检

```
EchoNote.exe --self-test
```

逐项列出原生依赖（ctranslate2 / onnxruntime / av）、前端资源、模型状态。

## 这一版改了什么

### 默认模型换成高精度档

v0.9.0 用 `small`（464 MB），这一版默认 `large-v3-turbo`（1.6 GB）。

同一段 8.95 s 样例音频，本机实测：

| 模型 | 转写结果 | 字符错误率 |
|---|---|---|
| `small` | …回声笔记的**时时**语音识别测试… | 17.2% |
| `large-v3-turbo` | …回声笔记的**实时**语音识别测试… | 13.8% |

代价是速度。同一台 4 核机器上，turbo 整段 RTF 1.49、3 秒句子折算 4.0——
**字幕会落后于说话**。界面上会直接显示「比说话慢约 N 倍」，可在「识别模型」里
一键切回「快速」档（需先 `EchoNote.exe --fetch-model small`）。

### 离线变成一等公民

- 模型在磁盘上时，加载直接使用本地路径，不做任何 Hub 查询——不是"缓存可能命中"。
- 新增 `fetch-model.bat` / `EchoNote.exe --fetch-model`：一次性下载，之后断网可用。
- `--offline` 强制零联网；缺模型时立刻报错并给出应放置的路径，不会卡在下载上。
- 界面出现绿色「离线可用」角标，表示当前进程加载的就是本地权重。

### 分词与解码

- VAD：停顿 650→900 ms、最短语音 280→240 ms、单段上限 15→30 s。句子更少更长，上下文更完整。
- final 增加温度回退与 `condition_on_previous_text`；中文 prompt 改为「请使用简体中文和标点符号转写」。
- 实测 decode 参数对耗时影响在 7% 以内，真正的瓶颈是模型规模与分段粒度。

### 新增接口

- `GET /api/models` —— 列出档位、体积、是否已安装
- `POST /api/model` —— 切换已安装模型（只读本地，绝不触发下载）
