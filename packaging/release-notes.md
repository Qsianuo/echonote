## 下载后怎么用（Windows，不需要装 Python）

1. 下载下面的 `EchoNote-v0.9.0-windows-x64.zip`（约 102 MB）
2. 解压到**任意可写目录**，例如 `D:\EchoNote` —— 不要放在 `C:\Program Files`
3. 双击 `EchoNote.exe`，会弹出一个命令行窗口
4. 模型加载完成后浏览器自动打开，点麦克风开始录音
5. 关闭命令行窗口即退出

### 首次启动会下载约 464 MB 的识别模型

只下载一次，之后**完全离线可用**。国内网络慢就双击 `start-mirror.bat` 走镜像。

### 出问题先跑自检

```
EchoNote.exe --self-test
```

它会逐项列出原生依赖（ctranslate2 / onnxruntime / av）、前端资源、模型状态，
把结果贴到 issue 里就能定位。

## 这个版本能做什么

- 实时把麦克风语音转成文字，**全程本地**，音频不离开这台电脑
- 八种语言：中 / 英 / 日 / 韩 / 法 / 德 / 西 / 俄，可自动识别
- 四种导出：TXT 文本、Markdown 笔记、SRT 字幕、WAV 原始录音
- 全键盘操作：空格开始 / 停止，导出菜单支持方向键与 Esc
- 读屏软件可播报状态与新增字幕

## 已知限制（技术预览，请勿当作 v1.0）

- **延迟约 4 秒**。开发机（8 核 + small 模型）实测 final 在 4.24–4.90 s，
  未达到 v1.0 设定的 p95 ≤ 3.0 s 门禁。这是它仍是 `v0.9.0 tech-preview` 的原因。
- 只提供 Windows x64 构建；macOS / Linux 请从源码运行（见 README）。
- 录音上限 90 分钟，超出会提示并停止（v1.0 前不做落盘）。
- 单次录音建议不超过 30 分钟，长时间录音的导出内存占用会上升。
