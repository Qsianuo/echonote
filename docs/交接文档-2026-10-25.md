## 一、项目背景与目标

**EchoNote 声记**（仓库 `github.com/Qsianuo/echonote`，MIT，作者 Qsianuo）：本地优先的开源录音 + 实时语音转写工具。

- **核心承诺**：录音与识别全部在用户设备上完成，音频不出设备；模型本地加载后完全离线可用
- **三端形态**：桌面（同一 HTML 套 Edge `--app` 窗口 + 内嵌 Python 服务）、Android（同一 HTML 套 Capacitor 壳 + 原生 sherpa-onnx 插件）、iPhone（暂走局域网 PWA，原生包待 Mac 构建）
- **当前版本**：**v1.0.0**（GitHub Release 已发布，PR #1 已合并，main HEAD = `7dff748`）
- **商业目标**：上架 Google Play / 国内安卓商店 / App Store（材料齐备，卡人工流程）
