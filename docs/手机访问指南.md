# 手机访问指南（局域网模式）

让手机和电脑连同一个 Wi-Fi，用手机浏览器（或添加到主屏幕后的 PWA）使用电脑上运行的 EchoNote。
识别仍在电脑上完成，音频与转写不出局域网。

## 启动

双击项目根目录的 **`启动手机访问.bat`**（或命令行 `python tools/serve_lan.py`）。
窗口会打印一个带令牌的地址、二维码和首次配置步骤，默认 **HTTPS 端口 8443**。

- 首次启动若 Windows 防火墙弹窗，选择「允许」。
- 地址里的令牌固定保存在 `models/lan-token.txt`，重开不变，可放心收藏。
- 局域网 IP 变化（换 Wi-Fi/路由器重启分配新 IP）时，证书会自动重新生成，
  手机上的旧地址失效，用新打印的地址即可（令牌不变，但要重新访问一次新地址）。

## 手机首次配置（每台手机一次）

浏览器不允许非 HTTPS 页面使用麦克风，所以首次要把本机自签证书加入手机信任：

1. 扫启动窗口里的二维码打开页面 → 提示证书风险 → 「继续访问」（此时界面能用，但录音键不可用）
2. 手机浏览器再访问 `https://<电脑IP>:8443/lan-cert.pem` 下载证书
3. **安卓**：设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书 → 选中下载的文件
   （不同厂商路径略有差异，搜「安装证书」即可）
4. **iOS**：Safari 下载后 → 设置 → 「已下载的描述文件」→ 安装 →
   再到 设置 → 通用 → 关于本机 → 证书信任设置 → 打开对该证书的「完全信任」
5. 回到页面刷新，录音键可用

**安卓免装证书的替代**：USB 连接电脑并开启调试，执行
`adb reverse tcp:8443 tcp:8443`，手机改用 `http://localhost:8443/?token=<令牌>`。

## 添加到主屏幕（PWA）

- **安卓 Chrome**：菜单 → 添加到主屏幕/安装应用
- **iOS Safari**：分享 → 添加到主屏幕

之后从图标启动即为独立窗口。令牌已存在手机本地（localStorage），无需每次输入。

## 常见问题

| 现象 | 处理 |
|---|---|
| 手机打不开页面 | 电脑防火墙未放行；或手机与电脑不在同一 Wi-Fi；核对启动窗口打印的 IP |
| 页面能开、录音键不可用 | 证书未信任（按上面首次配置做），或用了 `--http` 启动 |
| 换网络后地址失效 | IP 变了，用启动窗口新打印的地址 |
| 想换令牌 | 删除 `models/lan-token.txt` 后重启启动器 |

## 安全说明

- 服务绑定了 `0.0.0.0`，同一局域网内任何人都能打开页面，因此**必须**带令牌访问
  （WebSocket 校验令牌，无令牌无法录音/转写）。公共 Wi-Fi 下不要使用此模式。
- 电脑休眠/关机后手机端即断开；手机端录音数据存在手机浏览器里，导出也在手机上进行。
